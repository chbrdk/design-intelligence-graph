# ADR-004 — Visual Tokens Before Aesthetic Interpretation

**Status:** Accepted  
**Date:** 2026-08-14

## Decision

Emit style and asset summaries as deterministic DIG-004 L2 records, and keep any visual-language descriptions in a separate L3 hypothesis collection with bounded confidence and explicit evidence.

## Consequences

The output is useful to retrieval and generation without concealing subjective judgments as observed fact. Screenshot-vision analysis can later add richer hypotheses without changing the stable token contract.
